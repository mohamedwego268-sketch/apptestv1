# Family Space 🏠

تطبيق ويب متكامل مصمم لمساعدة الآباء في إدارة حياة العائلة وتنظيم المهام اليومية للأطفال بطريقة تفاعلية وذكية.

## المميزات الأساسية (Features)
- **ملفات الأطفال (3D Profiles):** إنشاء ملفات شخصية وتتبع النمو والسجلات الصحية[span_1](start_span)[span_1](end_span).
- **الروتين اليومي (Daily Routine):** إدارة مهام الأطفال مع نظام تنبيهات وتذكيرات ذكية[span_2](start_span)[span_2](end_span).
- **التقويم العائلي (Family Calendar):** جدولة المواعيد (ميلادي وهجري) ومتابعة الأحداث[span_3](start_span)[span_3](end_span).
- **نظام المكافآت (Wishes & Goals):** تتبع أمنيات الأطفال ونسبة إنجازها[span_4](start_span)[span_4](end_span).
- **المساعد الذكي (AI Assistant):** تقديم إرشادات تربوية مخصصة للآباء بناءً على المرحلة العمرية[span_5](start_span)[span_5](end_span).
- **التوافق اللغوي:** دعم كامل للغتين العربية والإنجليزية مع إعدادات مخصصة للعملة والبلد[span_6](start_span)[span_6](end_span).

## التقنيات المستخدمة (Tech Stack)
- React 19 & TypeScript
- Vite
- Tailwind CSS
- Firebase Integration
